## 🎮 怎么玩

### 第 1 步 · 找开服的人要一条「邀请链接」

长这样（`?ws=` 后面那串就是联机服务器地址）：

```
https://sch114514.github.io/stronghold-20p/?ws=<编码后的服务器地址>&room=四位密钥
```

> 直接打开本仓库首页（不带 `?ws=` 参数）是**连不上服务器**的，
> 一定会看到「连接中断，正在重连」——这是正常的，请务必用邀请链接进。

### 第 2 步 · 用浏览器打开它

**不需要安装任何东西。** 推荐最新版 Chrome / Edge / Firefox / Safari。

手机、平板记得**横屏**。

### 第 3 步 · 进房间

1. 输入「博士代号」，点「开始」
2. 链接里带 `&room=XXXX` 时会**自动加入**该同盟
3. 没带的话，在大厅的「加入同盟」里输入 **4 位同盟密钥**（找开服的人要）

### 第 4 步 · 玩

| 模式 | 说明 |
|---|---|
| 独立模拟 | 一个人玩，休整期不限时 |
| 同盟模拟 | 1–4 人合作，共享干员池；人不够可由 AI 补位 |

常用快捷键：<kbd>R</kbd> 刷新 · <kbd>F</kbd> 冻结 · <kbd>D</kbd> 升级 ·
<kbd>Space</kbd> 准备就绪 · <kbd>Esc</kbd> 关闭弹窗 · 右键查看详情

## ❓ 打不开 / 进不去

| 现象 | 处理 |
|---|---|
| 一直「连接中断，正在重连」 | 开服那位的**服务器或穿透隧道没开**，找他确认；或者你用的不是邀请链接 |
| 页面一直转圈、空白 | 换最新版 Chrome / Edge；手机建议用 Chrome |
| 素材是占位图、没声音 | 资源还没加载完，等一会儿或刷新页面 |
| 第一次加载特别慢 | 首次要按需下载较多图片和音频，之后走浏览器缓存就快了 |
| 掉线了 | 10 分钟内用**同一个浏览器、同一个网址**刷新可以回到原座位 |
| 提示「你已在其他同盟中」 | 先点「离开同盟」再加入新的 |
